# Funniest One-Line Out-of-Office Reply

Entry for [u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8](https://make.fun/c/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8)
($2 prize, free entry). The program writes one original out-of-office
auto-reply line to `/output/entry.txt`.

## The line

> Out of office — my inbox is now being handled by the void, and the void is also on leave.

89 characters, one line. The joke turns the usual "your email is being
handled while I'm away" line on its head: the stand-in handler is the void,
and even the void has clocked out — so the sender gets the laugh on the
first read, and the message still reads like something a real person would
switch on before going away.

## Run

```sh
node main.ts   # Node 22.18+ (grader runs Node 22.23.4)
```

Writes `/output/entry.txt` (UTF-8, 1–160 characters, single line — inside
the competition gate) and prints the character count. Deterministic: the
same line every run, byte-identical output.
